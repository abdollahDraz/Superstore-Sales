# 📊 Superstore Sales Dashboard - Power BI

## 📌 Overview

This project presents an interactive **Sales Analysis Dashboard** built using **Power BI** to analyze Superstore sales data across multiple dimensions including time, products, customers, and shipping.

The dashboard provides clear insights to support data-driven decision-making and improve business performance.

---

## 🎯 Objectives

* Analyze overall sales performance
* Track sales trends over time
* Identify top-performing products and categories
* Understand customer segments
* Evaluate shipping performance

---

## 📊 Key KPIs

* 🧾 Total Orders: **9800**
* 💰 Total Sales: **2.26M**
* 📈 Growth Rate: **46.90%**
* 📊 Average Sales: **230.77**
* 🌍 Top Region: **West**
* 👥 Top Segment: **Consumer**

* Consumer segment dominates overall sales
* Technology category is the best-performing
* Some products and sub-categories underperform
* Standard shipping is the most used shipping method
